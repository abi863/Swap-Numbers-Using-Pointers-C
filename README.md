# Swap Two Numbers Using Pointers in C

## Description

This program swaps two integers using pointers and a separate function. It displays the values before and after swapping.

## Concepts Used

* Pointers
* Functions
* Call by address
* Temporary variables
* `scanf()` and `printf()`

## How to Run

```bash
gcc swap_pointers.c -o swap_pointers.exe
./swap_pointers.exe
```

## Language

C
